# Real Estate Listing Manager

A simple command-line tool to manage real estate property listings. Add new listings, filter them by location or price, and store everything locally.

## Features

- Add a new property listing (address, price, location)
- Filter listings by location, max price, or both
- Data is saved locally in listings.json between runs

## How to Run

1. Make sure Python is installed
2. Create and activate a virtual environment:


python -m venv .venv source .venv/Scripts/activate 3. Run the app: python main.py ```
